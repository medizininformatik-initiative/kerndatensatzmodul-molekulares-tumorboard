### Inhalt
Mit dieser Extension können Quellen spezifiziert werden, die den angegebenen Evidenzgrad einer Empfehlung des molekularen Tumorboards belegen.
Diese Quellen sollten nach Möglichkeit als DOI oder per PubMed-ID angegeben werden.
