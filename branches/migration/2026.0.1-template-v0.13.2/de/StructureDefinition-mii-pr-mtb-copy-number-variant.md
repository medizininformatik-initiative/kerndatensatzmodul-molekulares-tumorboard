Copy Number Variant (CNV) 

-------

### Inhalt

Dieses Profil beschreibt die Copy Number Variante. Eine CNV kann nur ein einzelnen Genabschnitt, ein Gen oder einen Chromosomabschnitt mit mehreren Genen umfassen. Um dieser Tatsache gerecht zu werten, wurden ergänzend zum HL7 Clinical Genomics Reporting Implementation Guide folgende Datenpunkte durch dnpm erarbeitet:

* Gesamtzahl der CNVs
* Anzahl der einzelnen Allele A und B
* Relative Copy Number
* Focality
* betroffene Gene
* copy-number-neutrales Loss-of-Heterozygocity
