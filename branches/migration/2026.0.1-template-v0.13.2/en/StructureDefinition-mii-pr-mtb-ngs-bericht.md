NGS-Bericht zu einer Probe 

-------

### Content

This profile describes the NGS-Bericht (NGS report), which references the patient and the specimen and contains several Observations as result elements. The metadata of the report (devices, kits, library) are coded via GenomicStudy / GenomicStudyAnalysis.
